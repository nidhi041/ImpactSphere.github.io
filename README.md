#  Hackathon Volunteer Management System

> Built by **Team Impact Sphere** during the Innov8 Hackathon — a web-based platform designed to streamline volunteer management, registration, and task coordination.

---

##  Project Overview

The **Hackathon Volunteer Management System** is a web application designed to help organizers manage volunteers during large-scale events.

The project provides pages and functionality related to volunteer registration, event categories, information, contact, and task coordination.

Impact Sphere was developed collaboratively by Team Impact Sphere as part of the Innov8 Hackathon.

##  Setup & Installation

### 1. Clone the repository

```bash
git clone https://github.com/nidhi041/ImpactSphere.github.io.git
cd ImpactSphere.github.io
```

### 2. Run the project

This project is a static web application and does not require a package manager or dependency installation.

Open `index.html` in a web browser to run the application locally.

Alternatively, the project can be served using any static web server.
